# Ảnh thành viên

Đặt ảnh thủ công trong thư mục này theo quy tắc:

`[họ tên không dấu viết liền][năm sinh].webp`

Ví dụ `Nguyễn Văn Minh`, sinh năm `1990` → `nguyenvanminh1990.webp`.

Ảnh là static asset của GitHub Pages, không được mã hóa cùng `data.enc`. Không đặt ảnh cần bảo mật tuyệt đối vào thư mục public này.
