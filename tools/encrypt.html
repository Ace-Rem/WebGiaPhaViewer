Family Data Encryptor

Kiểm tra và mã hóa JSON gia phả ngay trên máy của bạn. Công cụ này không gửi dữ liệu đi đâu.

Chưa có dữ liệu để kiểm tra.
QUY TRÌNH
1. Chuẩn bị
Tạo hoặc chỉnh sửa file JSON nguồn trên máy cá nhân.
2. Kiểm tra
Dán JSON vào ô bên trái. Các lỗi tham chiếu nghiêm trọng sẽ chặn việc mã hóa.
3. Mã hóa
Mật khẩu được dùng để tạo khóa PBKDF2 rồi mã hóa bằng AES-GCM.
4. Cập nhật
Đặt file tải xuống vào thư mục gốc website với tên data.enc.
Lưu ý
Hãy giữ lại JSON nguồn và mật khẩu ở nơi backup riêng. Không commit JSON plaintext lên repository public.
